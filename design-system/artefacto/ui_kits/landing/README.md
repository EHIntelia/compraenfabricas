# Landing UI kit (mobile-first)
Clase en vivo funnel: `LandingScreen` (header, hero, aprendizajes, regalo, sobre Eduardo, planes, FAQ, footer) → `RegisterScreen` → `ThanksScreen`.
Composed only from DS components (Button, Badge, GradientText, Logo, Card, CheckItem, PeachBox, PricingCard, Accordion, Input, Select, Radio, Checkbox).
No production landing source was provided; layout follows the brand brief (mobile-first, crema bg, gradient CTAs, peach badges). Copy is illustrative.
