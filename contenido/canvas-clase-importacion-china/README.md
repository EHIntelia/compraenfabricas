# Canvas · Clase Importación China (copia)

Copia en el repo del canvas de diseños de la clase de importación de China: https://claude.ai/artifact/AJtuKHrqGFKxq3tsV6nVtp (privado; se comparte desde Share).

- **Fuente de verdad:** el canvas en claude.ai. Esta carpeta es un respaldo; si se cambia algo allá, hay que volver a copiarlo aquí.
- **Copiado:** 23 nov 2026 (versión con 45 diseños).
- **Formato:** cada diseño es un archivo `.dc.html` (HTML + CSS; las animaciones son CSS puro). `canvas.json` es el índice: posición, tamaño y título de cada diseño en el canvas.
- **Design System:** `ds/compraenfbricasdesignsystem_e5b2dc/tokens.json` (copia completa del sistema en [`design-system/`](../../design-system/)).
- **Imágenes:** `assets/` tiene las fotos subidas al canvas, nombradas por su id. En los `.dc.html` aparecen como `/_blob/<id>`; para abrirlas fuera del canvas, cambia esa ruta por `assets/<id>.jpg`.
